# Feedback ("Conta pro Eco") Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A small, lively, non-modal card in the desktop app where a person tells the team about a bug, a freeze, an idea or praise, with app context attached and stored on the server for a future admin panel.

**Architecture:** One zod contract in `packages/shared`; a `feedback` table plus `POST /feedback` (multipart) and `GET /feedback/@me` on the Fastify API; three new `window.alga.app` bridges in Electron main (recent log, window capture, crash marker); a lazy `features/feedback` module in the renderer (pure logic, zustand store, card, crash offer) following `features/whatsnew`.

**Tech Stack:** TypeScript, zod, Fastify + drizzle (PostgreSQL / pglite in tests), Electron (main/preload), React + zustand + `motion/react`, CSS modules, vitest, Playwright (`_electron`).

**Spec:** `docs/superpowers/specs/2026-11-09-feedback-design.md` — read it first; this plan argues from it. Visual reference (direction A, live): `.superpowers/brainstorm/408-1794265522/content/feedback-forma.html`.

## Global Constraints

- No icon in the rail, nothing near the spaces. Entry points are exactly: Ctrl K action, the user popover item, Settings › Avançado row, and the crash offer.
- The card is **not modal**: no scrim, `aria-modal="false"`, the app stays usable behind it. Width ≈ 400 px, bottom-left, above the user panel.
- Kinds: `bug` · `crash` · `idea` · `praise`. Default kind: `idea`. Text 1–2000 chars after trim.
- Log goes only for `bug`/`crash`, on by default, removable; at most 200 lines and 48 KB. Screenshot: one, PNG/JPEG/WebP, ≤ 8 MB.
- Context never carries names or ids of spaces, channels or people.
- Rate limit: 10 per hour per person.
- Everything that animates is `transform`/`opacity`, uses `ui/motion.ts` curves, and stops under reduced motion (states stay visible). No sound.
- Copy is pt-BR and fixed by the spec (questions per kind, "Vai junto", "Recebido. Valeu, {primeiro nome}!", "Travei da última vez. Quer me contar o que aconteceu?", "Contar", "Agora não", "Seus envios", "Nada por aqui ainda.", "Confira: o print mostra o que estava na tela.").
- Tone hex per kind (design-system tokens): bug `#e66e68`, crash `#e6b463`, idea `#8b8ef7`, praise `#61c28e`.
- No new dependencies. No admin/staff route, no status column, no screenshot download route.
- Work on a branch `feat/feedback` (the repo is on `main`). Commit style: `feat(feedback): …`, ending with `Co-Authored-By: Claude <noreply@anthropic.com>`.

## Review Focus

1. **Send fails or the network is down** → text, kind and screenshot stay in the card, "Tentar de novo" resends the same payload. (Task 4 test)
2. **A file that is not an image, or over 8 MB, sent as the screenshot** → 400/413 with a pt-BR field message, no row, no stored object. (Task 2 test)
3. **Client lies about the log** (log on `idea`/`praise`, or over 48 KB) → dropped for those kinds, 400 when too large. (Task 2 test)
4. **11th send in an hour** → 429; the card shows the server sentence and keeps the text. (Task 2 + Task 4 tests)
5. **Crash marker is corrupt, from this same process, or older than 7 days** → no offer, file removed, app starts normally. (Task 3 test)

export type FeedbackKind = (typeof FEEDBACK_KINDS)[number]
export const FEEDBACK_TEXT_MAX = 2000
export const FEEDBACK_LOG_MAX_LINES = 200
export const FEEDBACK_LOG_MAX_BYTES = 48 * 1024
export const FEEDBACK_SCREENSHOT_MAX_BYTES = 8 * 1024 * 1024
export const FEEDBACK_PER_HOUR = 10
export const FEEDBACK_CRASH_KINDS = ['renderer', 'main', 'unresponsive'] as const
export type FeedbackCrashKind = (typeof FEEDBACK_CRASH_KINDS)[number]
/** Closed on purpose (`.strict()`): never a name or an id. */
export const FeedbackContext = z.object({
  view: z.enum(['home', 'dm', 'space']), inCall: z.boolean(), sharing: z.boolean(), cinema: z.boolean(),
  crash: z.enum(FEEDBACK_CRASH_KINDS).nullable(),
}).strict()
export type FeedbackContext = z.infer<typeof FeedbackContext>
/** The multipart text fields after `context` is JSON-parsed. */
export const FeedbackFields = z.object({
  kind: z.enum(FEEDBACK_KINDS), text: z.string().trim().min(1).max(FEEDBACK_TEXT_MAX),
  context: FeedbackContext, log: z.string().max(FEEDBACK_LOG_MAX_BYTES).optional(),
})
export const kindTakesLog = (k: FeedbackKind): boolean => k === 'bug' || k === 'crash'
/** What the sender gets back and sees in "Seus envios". */
export interface FeedbackItem { id: string; kind: FeedbackKind; text: string; createdAt: string; hasScreenshot: boolean }
```

export interface CrashMarker { kind: FeedbackCrashKind; at: number; version: string; pid: number }
export const CRASH_MAX_AGE_MS = 7 * 24 * 60 * 60 * 1000
/** render-process-gone reasons that are a crash: not 'clean-exit', not 'killed'. */
export const countsAsCrash = (reason: string): boolean
/** A marker worth offering: well-formed, written by another process, younger than 7 days. Else null. */
export function readMarker(raw: string | null, pid: number, now: number): CrashMarker | null
/** Last `maxLines` lines that fit in `maxBytes` (UTF-8), whole lines only. */
export function tailLog(text: string, maxLines = FEEDBACK_LOG_MAX_LINES, maxBytes = FEEDBACK_LOG_MAX_BYTES): string
/** The session before the current one: everything before the last ` INFO start v` line. */
export function previousSession(text: string): string

// feedback.ts (electron side)
export function markCrash(kind: FeedbackCrashKind): void   // writes userData/crash-marker.json; an existing marker is kept (first cause wins)
export function clearUnresponsive(): void                   // removes the marker only if its kind is 'unresponsive' and pid is ours
export function registerFeedbackIpc(): void

// bridge.ts, inside `app`
/** End of main.log (≤ 200 lines, ≤ 48 KB). `previous`: the session before this one (after a crash). */
recentLog(previous: boolean): Promise<string>
/** PNG of the app window as it is now, or null when it could not be captured. */
captureWindow(): Promise<Uint8Array | null>
/** The crash left by the previous session, read once (null when none, stale or malformed). */
takeCrash(): Promise<{ kind: 'renderer' | 'main' | 'unresponsive'; at: number; version: string } | null>
```
